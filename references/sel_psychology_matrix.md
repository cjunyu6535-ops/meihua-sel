# CASEL SEL 心理學矩陣與易學轉譯 (CASEL SEL Psychology Matrix)

## 1. 八經卦 × CASEL SEL 五大素養轉譯矩陣 (Trigram x SEL Competencies Matrix)

| 經卦 | 自我覺察 (Self-Awareness) | 自我管理 (Self-Management) | 社會覺察 (Social Awareness) | 關係技能 (Relationship Skills) | 負責任的決策 (Responsible Decision-Making) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **乾 (天)** | 辨識內在核心價值與抱負 | 設定高標準目標並堅毅執行 | 覺察個人影響力對團隊的作用 | 展現領導力與自主溝通 | 評估長遠戰略價值與自主責任 |
| **兌 (澤)** | 覺察分享欲與內在情緒喜怒 | 調節過度期待或社交焦慮 | 同理他人情感需求與傾聽 | 促進開放、和諧、平等的對話 | 考量團隊共識與情感雙贏方案 |
| **離 (火)** | 覺察洞察力與精神專注度 | 控制急躁衝動與情緒過熱 | 明察秋毫、同理他人困境脈絡 | 坦誠溝通、提升互動透明度 | 依據客觀資訊與透徹分析決策 |
| **震 (雷)** | 覺察突破現狀的動機與恐懼 | 調節急躁情緒、轉化焦慮為行動 | 覺察環境變化與危機訊號 | 帶動團隊士氣、直言溝通 | 迅速評估風險並採取果斷行動 |
| **巽 (風)** | 覺察對環境變化的適應彈性 | 避免猶豫不決、保持靈活策略 | 感知局勢風向與他人微妙心理 | 柔順協調、跨界溝通與合作 | 彈性調整計畫以適應動態變化 |
| **坎 (水)** | 覺察深層恐懼與不安全感 | 在逆境中保持平穩、培養韌性 | 深刻體察他人內在痛苦與隱憂 | 建立深層信任與心理安全感 | 慎始敬終、著重風險預防與防守 |
| **艮 (山)** | 覺察個人心理邊界與止步點 | 靜心沉澱、抑制盲目衝動 | 理解他人邊界與冷靜立場 | 設立健康溝通邊界、尊重個人空間 | 評估停看聽契機、追求穩健永續 |
| **坤 (地)** | 覺察承擔責任的勇氣與包容心 | 保持耐心、穩定支持與服務 | 深刻感受群體需求與整體氛圍 | 提供傾聽、支持與合作陪伴 | 兼顧大局福祉與長期永續責任 |

## 2. 體用生剋認知偏差重構 (Five Elements Reframing Matrix)

| 生剋關係 | 傳統定性 | CASEL SEL 心理學賦能重構 (Cognitive Reframing) |
| :--- | :--- | :--- |
| **用生體** | 大吉 | **外部支援與資源賦能**：善用外部協助，提升社會覺察與同理整合。 |
| **比和** | 平吉 | **內部和諧與團隊共鳴**：同頻共振，深化關係技能與夥伴合作。 |
| **體克用** | 小吉 | **主動掌控與目標推進**：積極掌控主導權，實現負責任的決策行動。 |
| **體生用** | 洩氣/付出 | **心理邊界與防耗竭修煉**：覺察能量過度輸出，學會設立健康界限。 |
| **用剋體** | 凶/受壓 | **心理韌性與高壓成長契機**：將外部壓力視為挑戰，修煉情緒調節。 |

## 3. 動爻 1~6 爻調節焦點 (Moving Line Regulation Focus Matrix)

| 動爻 | 發展階段 | SEL 情緒調節與行動焦點 (Self-Regulation Focus) |
| :--- | :--- | :--- |
| **初爻 (1爻)** | 萌芽起步期 | **謹慎覺察**：專注基礎準備，覺察初始動機，避免盲目冒進。 |
| **二爻 (2爻)** | 發展推進期 | **關係深化**：積極尋求內部溝通與同理合作，奠定堅實基礎。 |
| **三爻 (3爻)** | 轉折高壓期 | **情緒調節**：警惕過度自信或焦慮，建立心理韌性與風險控管。 |
| **四爻 (4爻)** | 決策考驗期 | **社會覺察**：審時度勢，覺察組織大局與外部利害關係人需求。 |
| **五爻 (5爻)** | 核心發揮期 | **責任決策**：發揮領導力與同理共融，做出全局效益最佳決策。 |
| **上爻 (6爻)** | 終局反思期 | **靜心自我管理**：知止不殆，審視終局，總結經驗並準備下一輪循環。 |
